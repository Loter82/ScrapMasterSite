Політика конфіденційності

Як ми збираємо, використовуємо й захищаємо вашу інформацію на сайті та в сервісі ScrapMaster. Останнє оновлення: вересень 2026.

1. Загальна інформація

Ця Політика конфіденційності пояснює в загальних термінах, як ScrapMaster обробляє інформацію відвідувачів сайту scrapmaster.com.ua та користувачів хмарного сервісу. Формальне повідомлення про обробку персональних даних, обов'язкове за Законом України «Про захист персональних даних» № 2297-VI (включно з переліком ваших прав, підставами обробки та порядком звернення зі скаргою), викладене в окремому документі — Персональні дані.

2. Які дані ми збираємо

2.1. Інформація, яку ви надаєте самостійно:

  • Ім'я — для персоналізації звернення
  • Номер телефону — для зв'язку з вами
  • Email адреса — для надсилання інформації про продукт
  • Назва компанії — для розуміння вашого бізнесу
  • Кількість пунктів прийому — для підготовки комерційної пропозиції
  • Коментарі — ваші запити та побажання

2.2. Інформація, що збирається автоматично:

  • IP-адреса — для аналітики та безпеки
  • Дані про браузер — для оптимізації роботи сайту
  • Час відвідування — для статистичного аналізу
  • Джерело переходу — для оцінки ефективності реклами
  • Поведінка на сайті — через Google Analytics

3. Аналітика та сторонні сервіси

Наш сайт використовує сторонні сервіси, кожен з яких обробляє дані відповідно до власної політики конфіденційності:

  • Google Analytics та Google Ads — аналіз відвідуваності сайту та оцінка ефективності рекламних кампаній. Детальніше: policies.google.com/privacy
  • Google Sheets — зберігання даних, надісланих через форми на сайті
  • Telegram Messenger — комунікація з клієнтами за їхнім запитом

Ми НЕ продаємо ваші персональні дані третім особам і НЕ передаємо їх для маркетингових цілей без вашої згоди.

4. Файли cookie

Сайт використовує файли cookie для роботи сайту, аналітики та маркетингу. При першому візиті ви бачите банер, де можете обрати, які категорії cookie дозволити. Повний перелік категорій, конкретних cookie та інструкція, як змінити свій вибір, — у Політиці cookie.

5. Як ми захищаємо ваші дані

Ми вживаємо організаційних та технічних заходів для захисту персональних даних:

  • Шифрування даних при передачі (HTTPS/SSL)
  • Обмежений доступ до персональних даних лише для уповноважених співробітників
  • Регулярне резервне копіювання
  • Захист від несанкціонованого доступу
  • Row-Level Security для даних клієнтів у хмарному сервісі

6. Міжнародна передача даних

Частина технічних партнерів (Google LLC) може зберігати дані на серверах за межами України. У таких випадках ми покладаємося на стандартні договірні положення ЄС та відповідні технічні заходи захисту цих партнерів.

7. Строк зберігання даних

  • Дані з форми запиту демо — до 3 років з моменту останнього звернення
  • Дані клієнтів — протягом дії договору та 3 роки після його завершення
  • Аналітичні дані — згідно з налаштуваннями Google Analytics (до 26 місяців)
  • Після завершення строків дані видаляються або знеособлюються

Як суб'єкт персональних даних, ви маєте право на доступ до своїх даних, їх виправлення, видалення, обмеження обробки, відкликання згоди та інші права, передбачені законодавством України. Повний перелік прав, порядок їх реалізації та контакт контролюючого органу — в документі Персональні дані.
